Politique de confidentialité

Dernière mise à jour : 25 novembre 2026

1. Qui sommes-nous

Cette politique explique quelles données le jeu Showdown Age utilise et pourquoi. Le jeu est créé par DC General Games Studio, un studio de DC General Electric LLC (États-Unis). Si vous avez des questions, écrivez-nous à l'adresse e-mail indiquée à la fin.

2. Les données que nous utilisons

  • Votre compte. Lorsque vous ouvrez le jeu pour la première fois, nous vous créons un compte invité avec un numéro qui identifie votre téléphone dans le jeu. Si vous choisissez de sauvegarder votre progression, nous enregistrons aussi votre adresse e-mail, votre nom d'utilisateur et votre mot de passe (le mot de passe est enregistré chiffré).
  • Votre partie. Votre ville, vos héros, vos ressources, vos batailles et vos achats dans le jeu.
  • Ce que vous écrivez. Les messages du chat et des clans. Les autres joueurs de ce chat les voient.
  • Les notifications. Si vous les autorisez, un numéro Firebase pour vous envoyer des notifications sur votre téléphone, votre langue et votre fuseau horaire. Le fuseau horaire est seulement le décalage en heures par rapport à l'heure universelle : nous n'utilisons pas votre position.
  • Données techniques. L'adresse IP et les journaux de connexion de nos serveurs, pour que le jeu fonctionne et pour détecter la triche et les abus.

3. Pourquoi nous les utilisons

  • Pour que vous puissiez jouer en ligne sans perdre votre progression.
  • Pour vous envoyer des notifications (attaques, travaux terminés). Vous pouvez les désactiver dans les Paramètres du jeu ou dans Android.
  • Pour que le jeu reste équitable : détecter la triche, les faux comptes et la fraude aux achats.
  • Pour vous répondre si vous nous écrivez.

4. Achats

Les achats avec de l'argent réel sont facturés par Google Play. Nous ne voyons jamais les données de votre carte : nous recevons seulement de Google la confirmation de l'achat, pour vous remettre ce que vous avez acheté.

5. Avec qui nous les partageons

Nous ne vendons pas vos données et ne les utilisons pas pour la publicité. Seuls ces services les utilisent, pour que le jeu fonctionne :

  • Google Firebase Cloud Messaging, pour envoyer les notifications sur le téléphone.
  • Google Play, pour facturer et confirmer les achats.
  • Le service qui fait tourner nos serveurs, qui enregistre les comptes et les parties.

Si la loi nous y oblige, nous pouvons être tenus de transmettre des données à une autorité.

6. Combien de temps nous les conservons

Tant que vous avez votre compte. Si vous vous déconnectez de votre compte, nous supprimons le numéro de notifications de ce téléphone. Si vous supprimez votre compte, nous supprimons vos données dans un délai maximal de 30 jours, sauf ce que la loi nous oblige à conserver (par exemple, l'historique des achats).

7. Supprimer votre compte

Pour supprimer votre compte et vos données, écrivez-nous depuis l'adresse e-mail de votre compte (ou indiquez-nous votre nom d'utilisateur) avec l'objet « Supprimer mon compte ». Nous vous confirmerons quand ce sera fait. La suppression du compte est irréversible et ne rembourse pas les achats.

8. Enfants

Le jeu ne s'adresse pas aux enfants de moins de 13 ans et nous ne leur demandons pas sciemment de données. Si vous pensez qu'un enfant de moins de 13 ans nous a fourni des données, écrivez-nous et nous les supprimerons.

9. Vos droits

Vous pouvez nous demander une copie de vos données, leur correction ou leur suppression. Selon l'endroit où vous vivez, la loi peut vous accorder d'autres droits ; écrivez-nous et nous vous aiderons.

10. Modifications

Si nous modifions cette politique, nous mettons à jour la date ci-dessus. Si la modification est importante, nous vous prévenons aussi dans le jeu.

11. Contact

E-mail : dcgeneralgamesstudio@gmail.com
